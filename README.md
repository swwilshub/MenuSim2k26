# Menu Simulator 2K26

A frantic pixel-art parody game about navigating menus. Tap through nested menus before the timer drains, dodge decoys like "Setings (Legacy)", survive cookie banners, runaway Skip buttons, dialog inception and menus that rearrange themselves. Collect 88 UI-item collectables (checkboxes, dropdowns, the Unclosable Popup…) from a fully 3D (Three.js) gacha Menu Box with a synthesised orchestral score with pity, ×10 pulls and legally required drop rates, and absorb pearls of wisdom. Tasks now mix in interactive UI mini-games (toggles, sliders, steppers, cookie consent, country lists, typing, CAPTCHAs, popup whack-a-mole, hold-to-install, colour and date pickers, list sorting, password rules, settings tabs, nested accordions, patience bars, 2FA codes and slide-to-unlock), and every 4 tasks you reach the Drawing Room: a calm safe room with its own music, a typewriter save point and ink ribbons.

**Play:** https://swwilshub.github.io/MenuSim2k26/

Single static file (`index.html`), deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`. Progress is saved in your browser's localStorage.
